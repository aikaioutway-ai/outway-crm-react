# OutWay Telegram Driver Bot

Telegram-бот для запуска школьных трансферов и передачи Live Location в CRM.

## Новый сценарий

1. Логист или менеджер создаёт отдельную Telegram-группу трансфера.
2. Добавляет `@outway_driver_bot` администратором.
3. Бот автоматически создаёт в CRM заявку «Ожидает подключения».
4. В разделе «Водители» сотрудник открывает карточку назначенного водителя,
   выбирает Telegram-группу и трансфер, затем нажимает «Подключить».
5. Бот публикует одноразовую кнопку подтверждения. Назначенный водитель
   открывает её в личном чате и делится своим контактом кнопкой Telegram.
6. Бот сравнивает номер контакта с основным и дополнительным номером карточки
   водителя в CRM. Только после совпадения в группе появляется кнопка
   `▶️ НАЧАТЬ РЕЙС`.
7. Направление определяется по времени Бишкека: до 14:00 — утренний рейс,
   после 14:00 — вечерний.
8. После запуска водитель включает Telegram Live Location. Если за 90 секунд
   координаты не пришли, бот автоматически напоминает об этом в группе.

Команды `/verify`, `/register_transfer` и `/panel` больше не участвуют в
рабочем сценарии. Привязку группы и подтверждение назначения контролирует
сотрудник CRM.

## Ограничение Telegram

Bot API не разрешает боту самостоятельно включить GPS или Live Location на
телефоне пользователя. Поэтому одно действие водителя остаётся обязательным:

`Скрепка → Геопозиция → Транслировать геопозицию → 8 часов`.

Для полностью автоматического фонового GPS потребуется отдельное приложение
водителя или установленный в машине GPS-трекер.

## Безопасность

- Telegram webhook проверяется через
  `X-Telegram-Bot-Api-Secret-Token`.
- Действия CRM подписываются короткоживущей серверной сессией сотрудника.
- Подключать группы могут только роли `admin`, `manager`, `logist` и
  `senior_logist`.
- Одноразовое приглашение водителя хранится только как SHA-256 hash и действует
  24 часа.
- Нажатия ссылки недостаточно для привязки: Telegram ID сохраняется только
  после совпадения собственного контакта с номером выбранного водителя в CRM.
- Логист может отозвать прежнее подтверждение и отправить новое приглашение
  кнопкой «Переподтвердить» в карточке водителя.
- Таблица Telegram-групп недоступна напрямую ролям `anon` и `authenticated`.

## Развёртывание

```sh
npx -y supabase@2.110.0 db push --linked
npx -y supabase@2.61.1 functions deploy employee-login --no-verify-jwt
npx -y supabase@2.61.1 functions deploy telegram-driver-bot --no-verify-jwt
```

Webhook должен получать:

```text
message, edited_message, callback_query, my_chat_member
```

Секреты:

```sh
supabase secrets set TELEGRAM_DRIVER_BOT_TOKEN=<botfather_token>
supabase secrets set TELEGRAM_DRIVER_WEBHOOK_SECRET=<long_random_secret>
supabase secrets set TELEGRAM_DRIVER_BOT_USERNAME=outway_driver_bot
```

Не добавляйте токен бота или webhook secret в Git.
