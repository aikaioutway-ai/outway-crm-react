## Бизнес-правила

Пеня в OutWay CRM не используется. Второй и каждый последующий ребёнок семьи автоматически получает sibling discount 5% при создании/добавлении.

Удалять детей (например, дубли) может только администратор: ПКМ по ребёнку → «Удалить» с обязательной причиной. Запись уходит из CRM, а полная копия (ребёнок, начисления, семья — если ребёнок был последним) сохраняется в `v2_audit_log` (`action = 'child_delete'`). Удалить ребёнка с оплаченными начислениями или последнего ребёнка семьи, у которой есть платежи, нельзя — сначала разбираются оплаты. Остальные сотрудники используют «Отказ».

## Известные ограничения

Удалённая запись может вернуться, если вручную запустить полную перезаливку из Google Sheets (`uploadAllToSupabaseV2`).
